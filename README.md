# M.nemosyneLens

> **Status:** Still Under Development

An elite, high-contrast, zero-delay cinematic photography portfolio. Designed with an aggressive digital-noir aesthetic inspired by Rockstar Games and blended with ancient Italian-Greek stone-carved inscription accents.

## Features
- **Absolute Zero-Delay Entry:** Instant 3D glitch burst intro without passive loading screens.
- **Triple-Theme Matrix:** Instantly toggle between Dark Matrix, White Monolith, and Ancient Sulphur themes.
- **Interleaved Media Grid:** Seamlessly blends high-resolution photography with hardware-accelerated video reels.
- **Play-on-Hover Architecture:** Videos remain frozen as static thumbnails until hovered, preserving GPU threads.
- **Shutter Blade Lightbox:** Full-screen uncompressed media viewer wrapped in a bespoke camera HUD metadata layout.
- **GPU Optimized:** Built entirely on GSAP with `will-change` hardware acceleration and Lenis smooth scrolling.

## Tech Stack
- React / Next.js (App Router)
- Tailwind CSS
- GSAP (GreenSock) + ScrollTrigger
- Lenis Smooth Scroll
- next-themes
